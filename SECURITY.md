# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
**privately** rather than opening a public issue.

- Email: [security contact email to be filled in]
- Please include: a description of the issue, steps to reproduce, and the
  potential impact.

We aim to acknowledge reports within a few days and will keep you updated
as we work on a fix. Please give us reasonable time to address the issue
before any public disclosure.

## What We Consider In Scope

- Authentication or authorization bypass
- Exposure of secrets, credentials, or private user data
- Injection vulnerabilities (SQL, XSS, etc.)
- Anything that could compromise the integrity of Quran text or
  translation data in `quran-data`

## What's Out of Scope

- Issues requiring physical access to a user's device
- Social engineering
- Denial-of-service attacks against shared infrastructure (please report
  these too, but through the same private channel rather than testing
  them live)

Thank you for helping keep this project and its users safe.
