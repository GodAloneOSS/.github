## The contribution workflow

1. **Fork** this repository — click "Fork" at the top right of this page.
   This creates your own copy under your GitHub account.
2. **Clone** your fork to your computer:
   ```bash
   git clone https://github.com/YOUR-USERNAME/[repo-name].git
   cd [repo-name]
   ```
3. **Install** dependencies:
   ```bash
   [install command]
   ```
4. **Create a branch** for your change:
   ```bash
   git checkout -b fix/short-description
   ```
5. **Make your changes.**
6. **Test** your changes:
   ```bash
   [test command, or: manually check that ... still works]
   ```
7. **Commit** with a clear message:
   ```bash
   git add .
   git commit -m "Fix: short description of what changed"
   ```
8. **Push** to your fork:
   ```bash
   git push origin fix/short-description
   ```
9. **Open a Pull Request** — go to your fork on GitHub, click
   "Compare & pull request", and fill in the template.

A maintainer will review your PR, may ask for changes, and will merge it
once everything looks good and automated checks pass.
